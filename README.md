# FrontendAssignment

A modern and responsive frontend website developed using React.js and CSS.

## Project Overview

This project is a frontend implementation of a school website for Tulas International School (TIS).

The website presents information about the school, academics, sports facilities, campus experience, parent reviews, and admission enquiry.

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Framer Motion
- Lucide React
- Swiper.js

## Features

- Responsive school website
- Hero section with animated content
- School statistics section
- Sports and facilities section
- Campus video section
- Parent testimonials and reviews
- Admission enquiry form
- Navigation bar
- Footer
- Animations using Framer Motion
- Testimonial carousel using Swiper.js

## Installation

Install the project dependencies:

```bash
npm install
```

## Run Locally

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## Build

To create a production build:

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
